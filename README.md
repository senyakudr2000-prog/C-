# Последний сигнал

Полная сюжетная кампания для Minecraft Java 1.21.1 / Fabric.

Запуск: `/lastsignal start`
Цель: `/lastsignal status`
Финальный выбор: `/lastsignal choice transmit` или `/lastsignal choice destroy`
Сброс: `/lastsignal reset`

Кампания включает объект «Север-9», доктора Орлова, ключ-карту, три терминала, зачистку охраны и две концовки. TaCZ необязателен: игрок может использовать установленное оружие TaCZ, но мод не включает и не изменяет файлы TaCZ.

Честная граница версии: это законченная игровая кампания с диалогами в чате. Распознавание русской речи/Whisper и голосовой ИИ-диалог не реализованы и не заявляются.
